# Skill: tdd

## 目的
防止程式碼產生未測試盲點，確保每個功能模組與錯誤修復皆有可重複驗證之契約測試。

## 執行步驟
1. **Red（紅燈先行）**：在編寫任何產品程式碼前，依 Ticket 的 Given/When/Then 撰寫行為與契約測試案例，執行專案測試確認因缺實作而失敗。
2. **Green（最小綠燈）**：僅編寫使失敗測試通過的最少量實作程式碼，不順手改動無關模組。
3. **Refactor（安全重構）**：在測試持續全綠前提下消除重複與壞味道，並執行專案 `AGENTS.md` 指定的完整本地驗證指令確認 Exit Code `0`。
