# Skill: grill-with-docs

## 目的
在開始任何開發前，避免「盲目寫代碼」。Agent 將檢索 SecondBrain 知識庫，並像資深架構師一樣向使用者提出犀利的問題，鎖定細節與邊界。

## 執行步驟
1. **檢索知識庫與架構路由（優先）**：
   - 先讀取 `02-Areas/Software-Architecture/README.md` 路由表，依專案題型載入匹配的架構模式卡（若未命中再補讀 `02-Areas/` 相關領域筆記或既有專案規格）。
2. **提出問題 (Socratic Interview)**：
   - 若命中架構模式卡，先點出該架構的 **1–2 個最高風險反模式** 與「Explore → Expand」邊界，再優先詢問該卡的「開案必問 3–5 題」（並依實際規模裁切）。
   - 一次只專注在一組核心問題，不要一次問太濃縮。
3. **收斂與共識**：
   - 當使用者解答後，整理為清楚的需求條目與「採用的架構模式卡／偏離取捨」，準備轉交 `/to-spec`。
