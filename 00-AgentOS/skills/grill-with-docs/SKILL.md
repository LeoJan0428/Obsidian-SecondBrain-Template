# Skill: grill-with-docs

## 目的
在開始任何開發前，避免「盲目寫代碼」。Agent 將檢索 SecondBrain 知識庫，並像資深架構師一樣向使用者提出犀利的問題，鎖定細節與邊界。

## 執行步驟
1. **檢索知識庫**：搜尋 `02-Areas/` 或現有專案是否有相似概念、模組或規格。
2. **提出問題 (Socratic Interview)**：
   - 詢問 3-5 個關鍵問題（邊界條件、異常處理、資料結構、效能要求）。
   - 一次只專注在一組核心問題，不要一次問太濃縮。
3. **收斂與共識**：當使用者解答後，整理為清楚的需求條目，準備轉交 `/to-spec`。
