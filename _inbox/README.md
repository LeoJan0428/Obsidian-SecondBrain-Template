# 📥 SecondBrain 靈感與碎片收集箱 (_inbox/)

歡迎來到零阻力收集箱！

---

## 🎯 這是幹嘛用的？

在日常生活與高強度開發中，**千萬不要逼自己在第一時間寫出完美的筆記**。
無論何時，只要你：
- 看到一篇不錯的技術文章或 GitHub Repo
- 突然有一個專案新靈感或架構想法
- 遇到一個奇葩的 Bug 與解決指令
- 複製貼上了一段粗糙的會議記錄或代碼片段

👉 **不用管格式、不用管範本，直接建一個空白 `.md` 丟進這個 `_inbox/` 目錄！**

---

## 🔄 AI 圖書管理員消化 SOP (Weekly / Daily Review)

每隔幾天或每週，只要打開 IDE 對 AI 說一句話：

> 💬 *「請檢視 `_inbox/` 裡的所有草稿筆記，幫我將有價值的通用經驗提煉成原子筆記並存入 `02-Areas/` 或 `03-Resources/`，整理完畢後清空 `_inbox/`。」*

AI 會自動幫你：
1. 提取核心要點，去除冗餘廢話。
2. 加上標準 YAML frontmatter。
3. 建立雙向鏈接（WikiLinks）。
4. 歸檔至對應的長青領域，完成知識資產的自動複利！
